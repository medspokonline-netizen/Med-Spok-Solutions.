# Medspok Solutions Pvt Ltd Website

A fully static HTML website for **Medspok Solutions Pvt Ltd**, Chennai, showcasing medical equipment available for **rent and sale**.

## 📂 Files

- `index.html` – Home
- `products.html` – Products
- `rent-or-buy.html` – Rent or Buy
- `services.html` – Services
- `about.html` – About Us
- `contact.html` – Contact
- `medspok-catalogue-2026.pdf` – Product Catalogue

> Keep all files in the same folder.

## ✨ Features

- Pure HTML, CSS & JavaScript
- No framework or database
- Responsive design
- WhatsApp & Email enquiry
- SEO-friendly
- Works on any web host

## 🚀 Deployment

### Vercel

```bash
npx vercel login
npx vercel deploy --prod
```

Choose the current directory (`./`) and answer **N** when asked to modify settings.

### Netlify

Drag and drop the project folder into **https://app.netlify.com/drop**

## ⚠️ Troubleshooting

If you get **404: NOT_FOUND**:

- Make sure `index.html` is in the project root.
- Remove any `vercel.json` file.
- Leave Vercel build settings empty.
